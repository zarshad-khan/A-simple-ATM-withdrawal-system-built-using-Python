# Python ATM Withdrawal System

A simple ATM Withdrawal System built using Python. This mini-project allows users to withdraw money from an initial account balance while checking for sufficient funds and validating the withdrawal amount.

## Features

- Displays the available account balance.
- Allows users to enter a withdrawal amount.
- Checks for insufficient balance.
- Prevents invalid or negative withdrawal amounts.
- Calculates and displays the remaining balance.
- Displays transaction success or failure messages.

## Technologies Used

- **Language:** Python
- **Concepts:** Variables, Data Types, User Input, Conditional Statements (`if`, `elif`, `else`), Arithmetic Operators.
